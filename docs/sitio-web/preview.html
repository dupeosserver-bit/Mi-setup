Cómo instalar

GitHub: dupeosserver-bit/Mi-setup

Requisitos e instalación

Para tenerla encendida 24/7 necesitas un VPS. También puedes instalarla en tu PC, pero solo funciona mientras la PC esté prendida y conectada.

Mínimo

2 vCPU · 4 GB RAM · 40 GB de disco · Ubuntu · Docker

Recomendado

4 vCPU · 8 GB RAM · 100 GB de disco (para la IA gratis y los respaldos)

Dominio

Un dominio con DNS en Cloudflare (gratis) para el HTTPS y los sitios.

Ejemplo real: VPS del autor

Contabo · Ubuntu 22.04 · 96.7 GB de disco

Disco usado · 22.9 %

Memoria usada · 14 %

Pasos

  1. Renta un VPS (Contabo, Hetzner, DigitalOcean…) con Ubuntu y entra por SSH.
  2. En Cloudflare, apunta setup.tudominio.com a la IP del VPS.
  3. Instala:
    git clone https://github.com/dupeosserver-bit/Mi-setup.git /opt/mi-setup/app
cd /opt/mi-setup/app && sh deploy/instalar.sh
  4. Abre https://setup.tudominio.com, crea tu cuenta y activa el 2FA.
  5. Instala la app de Windows o Android y escribe la dirección de tu servidor.
